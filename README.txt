SHADRACK KYEI — BOOKS & PUBLICATIONS

This is a starter author website. Open index.html in a browser to preview it.

To put it online for free:
1. Create an account on GitHub (ask a parent/guardian to help with account setup if needed).
2. Create a new public repository named shadrack-kyei-books.
3. Upload index.html.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. GitHub will provide the public website address after deployment.

Before accepting payments, choose a provider that supports sellers in Ghana and have an eligible adult help with any required account, identity checks and payout setup. Do not publish private home or school details.

The current page is a design starter, not a payment-enabled store. Add the final approved book file, contact method, price, and checkout/download workflow before selling.
